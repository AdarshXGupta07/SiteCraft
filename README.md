## ✨ About This Project

This repository houses my personal freelance agency website, designed to attract high-ticket clients across specialized industries. It ditches generic templates in favor of a sleek, ultra-modern **"Light Tech"** design focused on raw performance, bespoke visual flair, and deep engineering precision.

From an integrated **360° scroll-driven laptop sequence** to ultra-smooth navigation powered by Lenis, every pixel was carefully crafted to prove one point: *I build exceptional websites.*

---

## 🚀 Key Features

- 🌀 **360° Laptop Scrubber**: Uses a canvas-based frame-rendering engine to scrub a photorealistic laptop through 120 frames bound to the user's scroll progression, seamlessly zooming into the next section.
- ⚡ **Light Tech UI**: A custom-designed light mode aesthetic utilizing deep blue/cyan neon glow effects (`#2563EB` & `#60A5FA`), premium typography, and dynamic glassmorphism layered over interactive elements.
- 🌊 **Silky Smooth Scrolling**: Powered by `Lenis` to provide an ultra-premium browsing experience, intercepting and softening hash anchors so navigating to the portfolio feels effortless.
- 🎯 **Targeted Dashboards**: Unique, AI-generated premium 3D assets to represent various development niches (e.g. Restaurants, Clinics, Boutique Hotels) in the interactive carousel.

## 🚦 Getting Started

To run the site locally and see the premium transitions in action:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/AdarshXGupta07/SiteCraft.git
   cd SiteCraft
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the development server:**
   ```bash
   npm run dev
   ```

4. **Experience the site:**  
   Open [http://localhost:3000](http://localhost:3000) in your browser. Scroll down slowly to watch the laptop unmount transition!
